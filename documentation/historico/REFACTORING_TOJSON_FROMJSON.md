# Refactoring: Using toJson() and fromJson() in SQL Managers

## Summary

This refactoring updates the SQL managers (`cliente_sql_manager.dart`, `produto_sql_manager.dart`, `nota_fiscal_sql_manager.dart`) to use the `toJson()` and `fromJson()` methods generated by `json_serializable` instead of building Maps manually.

## Changes Made

### 1. ProdutoSqlManager

**Before:**
```dart
final Map<String, dynamic> dados = {
  'nome': produto.nome,
  'codigo': produto.codigo,
  'preco': produto.preco,
  'estoque': produto.estoque,
  'descricao': produto.descricao,
  'categoria': produto.categoria,
  'data_cadastro': produto.dataCadastro.toIso8601String(),
};
```

**After:**
```dart
final Map<String, dynamic> dados = produto.toJson();
// Remove the ID from the data map because it will be generated automatically
dados.remove('id');
```

**`_mapToProduto` method:**

**Before:**
```dart
Produto _mapToProduto(Map<String, dynamic> map) {
  return Produto(
    id: map['id'] as int,
    nome: map['nome'] as String,
    codigo: map['codigo'] as String,
    preco: (map['preco'] as num).toDouble(),
    estoque: map['estoque'] as int,
    descricao: (map['descricao'] as String?) ?? '',
    categoria: (map['categoria'] as String?) ?? '',
    dataCadastro: DateTime.parse(map['data_cadastro'] as String),
  );
}
```

**After:**
```dart
Produto _mapToProduto(Map<String, dynamic> map) {
  // Ensure optional fields have empty-string defaults
  final mapComDefaults = {
    ...map,
    'descricao': map['descricao'] ?? '',
    'categoria': map['categoria'] ?? '',
  };
  return Produto.fromJson(mapComDefaults);
}
```

### 2. ClienteSqlManager

The `Cliente` model has a nested `DadosCliente` structure that does not directly match the flat database schema. Helper methods were therefore added to convert between the two representations:

**Helper Methods Added:**
- `_clienteParaDadosDb()`: Converts a Cliente to a flat database Map.
- `_dadosDbParaClienteJson()`: Converts a flat database Map to a nested JSON structure.

**`_mapToCliente` method:**

**Before:**
```dart
Cliente _mapToCliente(Map<String, dynamic> map) {
  return Cliente(
    id: map['id'] as int,
    nome: map['nome'] as String,
    cpf: map['cpf'] as String,
    email: (map['email'] as String?) ?? '',
    telefone: (map['telefone'] as String?) ?? '',
    endereco: (map['endereco'] as String?) ?? '',
    dataCadastro: DateTime.parse(map['data_cadastro'] as String),
  );
}
```

**After:**
```dart
Cliente _mapToCliente(Map<String, dynamic> map) {
  // Prepare the data in the format expected by fromJson
  final mapFormatado = _dadosDbParaClienteJson(map);
  return Cliente.fromJson(mapFormatado);
}
```

### 3. NotaFiscalSqlManager

**`atualizar` method:**

**Before:**
```dart
final Map<String, dynamic> dadosNota = {
  'numero_nota': notaFiscal.numeroNota,
  'cliente_id': notaFiscal.clienteId,
  'cliente_nome': notaFiscal.clienteNome,
  'cliente_cpf': notaFiscal.clienteCpf,
  'valor_total': notaFiscal.valorTotal,
  'forma_pagamento': notaFiscal.formaPagamento,
  'data_emissao': notaFiscal.dataEmissao.toIso8601String(),
};

final Map<String, dynamic> dadosItem = {
  'nota_fiscal_id': notaFiscal.id,
  'produto_id': item.produtoId,
  'produto_nome': item.produtoNome,
  'produto_codigo': item.produtoCodigo,
  'quantidade': item.quantidade,
  'preco_unitario': item.precoUnitario,
  'valor_total': item.valorTotal,
};
```

**After:**
```dart
final Map<String, dynamic> dadosNota = notaFiscal.toJson();
// Remove fields that should not be updated
dadosNota.remove('id');
dadosNota.remove('itens');
// Add the calculated valor_total
dadosNota['valor_total'] = notaFiscal.valorTotal;

final Map<String, dynamic> dadosItem = item.toJson();
// Add fields required by the database
dadosItem['nota_fiscal_id'] = notaFiscal.id;
dadosItem['valor_total'] = item.valorTotal;
```

**`_mapToNotaFiscal` method:**

**Before:**
```dart
NotaFiscal _mapToNotaFiscal(
  Map<String, dynamic> notaMap,
  List<Map<String, dynamic>> itensMap,
) {
  final List<ItemNotaFiscal> itens = itensMap.map((itemMap) {
    return ItemNotaFiscal(
      produtoId: itemMap['produto_id'] as int,
      produtoNome: itemMap['produto_nome'] as String,
      produtoCodigo: itemMap['produto_codigo'] as String,
      quantidade: itemMap['quantidade'] as int,
      precoUnitario: (itemMap['preco_unitario'] as num).toDouble(),
    );
  }).toList();

  return NotaFiscal(
    id: notaMap['id'] as int,
    numeroNota: notaMap['numero_nota'] as String,
    clienteId: notaMap['cliente_id'] as int,
    clienteNome: notaMap['cliente_nome'] as String,
    clienteCpf: notaMap['cliente_cpf'] as String,
    itens: itens,
    formaPagamento: notaMap['forma_pagamento'] as String,
    dataEmissao: DateTime.parse(notaMap['data_emissao'] as String),
  );
}
```

**After:**
```dart
NotaFiscal _mapToNotaFiscal(
  Map<String, dynamic> notaMap,
  List<Map<String, dynamic>> itensMap,
) {
  final List<ItemNotaFiscal> itens = itensMap.map((itemMap) {
    return ItemNotaFiscal.fromJson(itemMap);
  }).toList();

  // Prepare the invoice map with its items for deserialization
  final notaComItens = {
    ...notaMap,
    'itens': itens.map((item) => item.toJson()).toList(),
  };

  return NotaFiscal.fromJson(notaComItens);
}
```

### 4. Model Updates

Added `explicitToJson: true` to the `@JsonSerializable` annotations to ensure that nested objects are serialized correctly:

**Cliente:**
```dart
@JsonSerializable(constructor: 'withDados', explicitToJson: true)
class Cliente extends DefaultObject {
```

**NotaFiscal:**
```dart
@JsonSerializable(explicitToJson: true)
class NotaFiscal extends DefaultObject {
```

## Benefits

1. **Less manual code**: Reduces repetitive serialization/deserialization code.
2. **Maintainability**: Model changes are automatically reflected in SQL managers.
3. **Consistency**: Uses the same serialization mechanism throughout the app.
4. **Fewer errors**: Reduces typos and fields omitted during manual serialization.
5. **Type safety**: Uses json_serializable code generation to ensure correct types.
